# 🧠 GPT-OSSとは？

OpenAIが公開した、**初の大規模オープンウェイトモデル（OSS LLM）**。

- 公開モデル：`gpt-oss-120b` と `gpt-oss-20b`
- ライセンス：**Apache 2.0（商用利用可）**
- 実行形式：ローカルで利用可能（API不要）
- 利用目的：ChatGPT相当のAIを**自分の環境で動かす・育てる**

---

## 🚀 特徴とメリット

| 項目             | 内容 |
|------------------|------|
| 💬 ChatGPT的応答 | 事前学習済み → 学習なしでも自然言語応答可 |
| 🔧 カスタマイズ   | 文体・機能・知識・出力形式を自由に制御可能 |
| 🧠 再学習可能     | Fine-tuning / LoRA 対応 → 自社GPTが育てられる |
| 🔍 RAG構成対応    | 資料を元に検索＋生成（Retrieval-Augmented Generation）構築可 |
| 💻 ローカル実行   | 完全オフライン・クラウド非依存・セキュア運用可能 |
| 📦 商用利用OK     | Apache 2.0 → アプリ/製品に自由に組み込める |

---

## 🧩 モデル構造（GPT-OSS-120B）

- Mixture of Experts 構造（MoE）
- 各レイヤー128 expert → トークンごとに4つ選択的にアクティブ
- 実行時は約5.1Bのパラメータのみ稼働
- 性能は o4-mini（GPT-4-lite）相当

---

## 📊 性能と立ち位置

| モデル名         | 性能目安 | 備考 |
|------------------|-----------|------|
| GPT-OSS-20B      | ≒ o3-mini | 軽量だが高精度 |
| GPT-OSS-120B     | ≒ o4-mini | 高性能・推論力あり |
| GPT-3.5          | 商用API   | 非公開 |
| GPT-4            | 商用API   | 非公開・超大型 |

## 🔗 Claude Codeとの類似点

Claudeの「サブエージェント」機能と似た構造：
- GPT-OSSでは「MoEによるトークンごとの専門家割当」が内部で行われる
- 並列思考・役割分担の概念が近い

## 💬 ユーザーの反応（要約）

## 📦 OSSとは？

- **Open Source Software**：中身が公開され、自由に使えるソフト
- GPT-OSSはモデル本体・構造・重みを完全公開
- Apache 2.0により再配布・商用・改変すべてOK
