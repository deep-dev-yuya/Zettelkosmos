# ⏰ n8n Cron式スケジューリングガイド

## ✅ 概要

n8nのトリガーノードにおける「Custom」モードでの `Cron Expression` 設定について解説します。

---

## 🔸 Cron式の基本構成

```
┌───────────── 分（0 - 59）
│ ┌───────────── 時（0 - 23）
│ │ ┌───────────── 日（1 - 31）
│ │ │ ┌───────────── 月（1 - 12）
│ │ │ │ ┌───────────── 曜日（0 - 6）※0は日曜日
│ │ │ │ │
│ │ │ │ │
* * * * *
```

---

## 🔁 例：5分ごとの実行

```
*/5 * * * *
```

これは「5分おきに毎分実行」を意味します。  
（例: 00分、05分、10分、15分...）

---

## 🧠 よく使うパターン

| 実行頻度           | Cron式             |
|--------------------|--------------------|
| 毎分               | `* * * * *`        |
| 5分おき            | `*/5 * * * *`      |
| 毎時0分            | `0 * * * *`        |
| 毎日9時            | `0 9 * * *`        |
| 毎週月曜9時        | `0 9 * * 1`        |
| 毎月1日0時         | `0 0 1 * *`        |

---

## 🛠 n8nでの設定手順

1. トリガーノードの **Mode** を `Custom` に変更  
2. **Cron Expression** フィールドに式を入力（例：`*/5 * * * *`）  
3. 設定完了！

---

## 📌 注意点

- `*` は「すべて」を意味します。
- 複雑な式の検証には [crontab.guru](https://crontab.guru/) などが便利です。
- n8nの内部では Node.js の cron パーサが使用されており、標準Cron式がそのまま使えます。
