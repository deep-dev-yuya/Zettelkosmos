## 🔧 技術詳細

### モデル仕様

| 項目 | 詳細 |
|------|------|
| **アルゴリズム** | LinearSVC + TfidfVectorizer |
| **学習データ** | 45件（各カテゴリ10-12件） |
| **分類カテゴリ** | 4つ（支払い関係、プロモーション、重要、仕事・学習） |
| **特徴量** | 最大2000語、N-gram(1,2) |
| **保存形式** | pickle (tuple: vectorizer, model) |

### 学習データ構成
```
支払い関係:   12件 (26.7%)
プロモーション: 10件 (22.2%)  
重要:        12件 (26.7%)
仕事・学習:   11件 (24.4%)
```

### 信頼度スコア分析
- **正分類の信頼度**: 0.460 ~ 0.542 (正の値)
- **誤分類の信頼度**: -0.429 (負の値)
- **判定境界**: 0付近で明確に分離
